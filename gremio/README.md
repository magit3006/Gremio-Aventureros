# Gremio de Aventureros

Proyecto integrador de DWES para las entregas de las UD3, UD4 y UD5.

## Uso de IA

Se ha utilizado IA como apoyo puntual durante el desarrollo:

- Para localizar los apartados pendientes y apoyar la implementación del login,
  las sesiones y las preferencias de cookies.
- Para revisar la sintaxis de PHP y explicar conceptos de seguridad y sesiones
  al completar la memoria.

El código y las explicaciones deben ser revisados por el alumno, que también
debe ejecutar y anotar personalmente las pruebas del proyecto.
